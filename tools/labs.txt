# Gate rows for tools/labs.sh, one per line:   name | timeout_s | godot args | flags
# godot args: engine flags, then "--" and the game's own flags (labs.sh adds --headless --path game).
# flags: "shot"        also captured by `tools/labs.sh --shots DIR` (web renderer, 1600x900)
#        "shotxfail:<PKG>"  the still is known to fail the exposure check (strict, like xfail)
#        "window"      runs windowed (silent, 1600x900) instead of headless: needs a display
#        "xfail:<PKG>" known red and owned by PKG. Strict: the row must fail by its own FAIL/PARTIAL
#                      verdict (a crash still fails the gate), and once it passes the gate fails
#                      until the flag is removed.
#        "flaky:<PKG>" the outcome varies run to run and PKG owns the cause: PASS or the row's own
#                      FAIL/PARTIAL verdict (shown as FLAKY) both keep the gate green; a crash,
#                      timeout or missing verdict still fails it. Only with run-to-run evidence.
#        "errors:N"    the row may log up to N engine ERROR lines (default 0)
# --fixed-fps 60 steps the game at exactly 60 Hz as fast as the CPU allows: same physics, less wall
# time. Never on perf rows (they time real frames), and never on the counter_* fight rows: combat
# cooldowns read the wall clock (Time.get_ticks_msec in creature_brain.gd, creature.gd, player.gd,
# vitals.gd), so a faster-than-realtime run changes who wins. New labs: one line each, appended at merge.
