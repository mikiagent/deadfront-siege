# Generated harvestable resources

Meshy production assets approved from the September 22, 2026 resource sprint.

- `resource-branch-final.glb`: forked deadwood branch, harvest/inventory prop.
- `resource-fibre_stalk-final.glb`: tall fibrous grass tuft, harvest node.
- `resource-berries-final.glb`: wild red berry sprig, harvest node/inventory prop.
- `resource-clay-final.glb`: raw reddish clay mound, harvest node/inventory prop.

Rejected/not integrated: stone cluster read as a birch log segment at gameplay size; herb_leaf had an unwanted planter dish; three wood-log attempts failed shape isolation (blocky or generated scene debris). Those need a different reference-driven route.

Biome mineral wave:
- `min-flint-final.glb`: temperate flint nodule cluster.
- `min-obsidian-final.glb`: tropical obsidian deposit.
- `min-ice-final.glb`: tundra/snowfield ice deposit.

Rejected from this wave: stone texture developed white patches; sandstone became a melted ground patch rather than a rock node; ochre preview was a shapeless ground patch. These remain unintegrated.
- `min2-copper_ore-final.glb`: desert copper/malachite deposit.
- `min2-salt-final.glb`: desert halite deposit.
- `min2-peat-final.glb`: swamp peat block deposit.
- `min2-black_iron-final.glb`: volcanic black iron deposit.

Rejected: silver ore texture bleached nearly white and does not read as silver-bearing host rock; mud geometry was a shallow shapeless depression.
