## Conflict-resolution notes

1. **Private island:** After confirmation the upgrade **automatically dismantles** the old home; a new larger higher-resource private home replaces it. The special salvage vault receives **100% returned building materials**, while residents, animals and ordinary inventory transfer separately. Unfinished construction and failure recovery OPEN.
2. **PvPvE entry:** The **tribe permanently remembers** the level-60 island unlock, but only a **currently controlled level-60 person** can enter PvPvE. A lower-level descendant must level up or switch to an eligible veteran.
3. **Equipment**: older documents mention hard gate vs effective cap as alternatives. The owner chose **hard gate**. Enforce on effective playable characters; exact item categories still to specify.
4. **Age**: level-related adult age and timed growth are **both required**; neither cancels the other. Needs a clear state machine.
5. **PvP scheduling**: prior workshop listed windows as a recommended option. The owner rejected this. No player-scheduled raid windows.
6. **Raid economy**: previous docs referred to loot primarily as exposed stockpiles; expanded owner-approved candidates include salvage, captives and equipment. Capture rules must be carefully specified to avoid overpowering economic progression.
7. **Research PRD**: original Durango implementation/snapshots contain era-dependent PvP, aging and no breeding. Those are **historical research**, not source requirements for this future Deadfront design.
9. **Island world reset and raids:** Terrain is never the player raid objective, only **PvPvE settlements**; **PvE settlements** can face animal attacks. Unstable islands **reset resources and auto-dismantle placed bases** to the dedicated salvage vault. This supersedes literal "sinks/disappears forever" claims until respawn geography is specified.
10. **Captives:** Prisoners have **72 real-world hours** to be ransomed at a **game-calculated price**. Ransomed individuals keep IVs, prior personal level/skills and trained EVs. If unpaid, attacker acquisition produces a **level-1 adult** retaining **original adult looks and IVs**, with fresh earned XP, skills and EVs. Exact claim/recruiting/price formula remains open; see the [ransom specification](16-pvp-frontier-siege-and-captives.md).
11. **Private resource cap:** top private homes supply level 50–55 resources; level 60+ must be obtained outside. Global 1–60 model needs an explicit compatibility ruling.
8. **Code reality vs target design**: current Godot project is solo-first with existing skill/item inventory and home island logic. This ledger does not establish that future switching, genetics, remote raid capture, larger islands or player-market protection already exist.
