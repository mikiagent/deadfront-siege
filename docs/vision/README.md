# Vision — permanent, evolving design

Vision is not implementation. This folder holds what the game should be — experience promises,
rules that shape every system, and open questions waiting for the balance workshop. It changes
under its owner's pen; nothing here describes what the build does today. For that, read
`../current/`.

## Rules when writing vision
- Cite section numbers (`WildLandsMMO_Game_Vision.md` §20), not paraphrases.
- Proposals stay proposals until the owner's balance workshop answers them; the letter is in
  `WildLandsMMO_Loss_Recruitment_Revival.md`'s deciders section and each math doc's closing
  questions.
- Unresolved points land in the Open Questions register (`WildLandsMMO_Open_Questions.md`)
  and move into the owning doc once the workshop decides.
