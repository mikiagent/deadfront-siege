## Guidelines for reading this table

- Current code is the integration base. If an owner rule conflicts, **do not ignore it or silently patch a save**. Create a migration ticket with before/after fixtures.
- `C00-C23` are domain IDs, not evidence that 24 new files must be created or a clean foundation built first.
- No generic M0 fresh project, invented `entities` root or duplicate World service.
- Every row may be split into small, independently playable feature slices, in dependency order.
