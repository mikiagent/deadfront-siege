# Durango:0 Homecoming Wiki Research Pack

**Compiled October 21, 2026.** 12 topic files, source-linked and designed for use as background/context for Claude implementing an original dinosaur survival game.

This is a curated research collection, **not a download of the complete wiki, its original data tables, its proprietary game files, or its source repository**. Direct fetching of the wiki site was unsuccessful in this session; accessible search-indexed source excerpts supported this pack. Check the linked original pages for full data and for newer revisions.
