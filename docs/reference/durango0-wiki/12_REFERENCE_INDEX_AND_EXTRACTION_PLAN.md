## How to make a true comprehensive offline research library
1. Open the linked wiki in a browser that can fetch the actual live site.
2. For each interactive data table, export/copy all rows or retrieve the underlying openly accessible data only when legally permitted.
3. Store complete tables as `skills.csv`, `recipes.csv`, `animals.csv`, `food.csv`, etc. Preserve source IDs and formula strings.
4. Save page version, original/restoration status and URL for every record.
5. Verify table counts and check that searches/filters haven't accidentally excluded hidden rows.
6. Never relabel project-added content as original Durango data.

## Source boundary
This package deliberately does not impersonate a complete wiki download. It documents the most actionable mechanics confirmed from indexed reference pages, while linking to primary tables for deeper work.
