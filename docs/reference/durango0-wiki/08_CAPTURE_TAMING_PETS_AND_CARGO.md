# Capture, taming, companion ranks and management

## Distinct stages
Encounter → weaken/stun or fulfill capture conditions → capture with applicable item/ability → deposit the captured animal in a pen → timed taming with optional feed → resolve success → bond → level/train/use companion.

The restoration's current pet page describes using Rein items, pen taming and feed improvements. Some original-player accounts describe a net action while the animal is stunned. These may reflect version differences or recreation changes; preserve a configurable capture interaction.

## Pet data and grades
The pet list includes 111 original pet entries. The current restoration uses Grade B 50%, A 40%, S 10% for eligible grades, with stat multipliers B 1.15, A 1.35, S 1.6 as documented; it says the weights use Nexon-published probabilities while current selection behavior is a developer choice. Candidate grades vary by species. C/D are not normally rolled in this implementation.

## Taming time
Restoration example: `1800s × (1 + reins_size / 10) × 0.5` where `0.5` is the **developer's two-times-faster work setting**, not the original normal timer. Feed can shorten the time and improve success.

## Companion roles
Riding speed, load capacity, Vigor, diet, combat eligibility and production (milk, eggs, feathers) are per-species fields. Some trained pets can produce resources or act as mobile storage. Keep bonded pet limit distinct from the number summonable on an island (wiki cites five released on one island).

## Capacity historical comparison
Historical accounts describe three initial bonded pet slots and upgrades via Animal Handling. Modern restorations can start with different limits. Keep values source-versioned and configurable.
